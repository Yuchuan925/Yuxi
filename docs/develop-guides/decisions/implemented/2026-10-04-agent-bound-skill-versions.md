# 专属 Skill 的当前内容与历史快照

状态：implemented
类型：feature
Owner：backend/yuxi/modules/extensions/skills/versions.py

## 问题

Agent 管理者需要保存当前指南、发版留存和恢复历史完整包。专属绑定的权限和执行准备属于[专属 Skill 决策](./2026-10-03-agent-bound-skill.md)，版本操作需要复用这些边界，并保持运行加载机制。

## 决策

Agent 始终使用一个稳定 Skill slug，保存更新当前内容；发版为当前已保存的完整内容记录历史。历史版本标识使用北京时间年月日与 UUID8，例如 `20261004-a1b2c3d4`；数据库唯一约束拒绝碰撞，不维护递增计数。

`SkillVersion` 保存所属 Skill 的级联外键、版本标识、目录引用、展示元数据、内容哈希和创建身份。当前内容与历史引用同一不可变完整包，包含根说明、依赖声明、辅助文件、空目录和执行位。展示元数据包含名称与描述，恢复内容与依赖由历史根文件拥有。历史包不进入普通 Skill 列表、依赖候选或运行投影，也不提供文件修改接口。

发版、恢复、删除和文件编辑共同沿用 Agent → Skill 锁序。前端恢复确认覆盖，后端以整包修订拒绝过期操作，并验证历史字节和当前依赖权限。恢复更新当前目录引用，不创建备份，不改变 slug。删除历史行后，仅清理没有当前或历史引用的目录；删除当前使用的历史仍保留当前内容。删除 Agent 时外键级联删除绑定与历史行，服务清理已定位的内容目录。业务 Schema 使用版本 4 的全新部署基线。

版本入口只用于专属 Skill。详情页共享完整内容草稿，文件区域或依赖区域提供“保存修改”；历史页签提供发版、恢复和删除。存在未保存草稿时禁用发版和恢复，避免静默丢失编辑。普通 Skill 复用内容提交与编辑界面，保留既有单文件 API，不提供历史功能。持久化与清理规则由[完整内容提交决策](./2026-10-05-skill-content-commit.md)拥有。

Run、沙盒和授权中间件保持既有加载机制。专属根说明保留同 Run 初始预加载文本，辅助文件读取实时用户投影；不提供完整包 Run 版本固定。

## 替代方案

| 方案 | 取舍 |
| --- | --- |
| 不可变运行版本与 Agent 切换 slug | 能固定整包执行，需要改变运行准备与投影；采用稳定 latest 以保持现有运行机制 |
| 在 Skill 表保存历史并加入版本类型 | 增加普通列表、权限、依赖和运行发现的排除分支；独立历史索引只由版本用例消费 |
| 递增编号或手工命名 | 需要计数或额外表单；采用日期与随机后缀 |
| 恢复前自动备份 | 增加未请求的隐式版本；恢复前确认，管理者需要保留时主动发版 |

## 后果

历史存储成本随完整包数量增长，管理者可以删除快照。恢复覆盖尚未发版的 latest 修改，不自动留存。恢复后的依赖若已停用或不能覆盖当前共享范围，操作失败，latest 保持原样。随机后缀的碰撞由数据库拒绝，管理者重新发版。

完整内容先落在新目录，数据库拥有可见当前引用与历史；提交失败删除新目录，旧引用保持有效。内容保存不刷新全部用户投影，运行准备按当前引用物化；授权失效的旧投影在权限提交前撤下。
## 验证

真实 HTTP 集成测试回读历史行、当前引用和字节，覆盖完整保存并发版、普通保存不修改历史、恢复、删除当前使用的历史和级联清理。负向测试验证过期修订、只读身份、普通 Skill 发版、历史损坏、当前依赖权限不满足以及 UUID 后缀碰撞。真实 PostgreSQL 并发测试证明过期保存只接受一个完整包；提交失败保持旧引用，提交后并发清理不影响已确定的响应。

真实 worker E2E 先发版、修改并恢复指南，再以空 skills/preload 配置执行，独立模型协议验证已恢复根、持久 manifest、投影与删除。既有运行中根编辑用例继续证明加载机制。前端行为测试执行实际组件，验证完整保存传递草稿和修订、历史页仅发版已保存内容、恢复与删除确认、409 保留内容，以及普通 Skill 隐藏版本入口。真实浏览器验证编辑、发版、覆盖恢复与删除；截图与准确执行结果记录在 PR。
